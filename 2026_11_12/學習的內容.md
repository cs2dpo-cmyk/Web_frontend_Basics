form 建立表單，可以讓使用者互動 
action 放在<form action="URL"....> 處理表單的資料位址(URL呈現)，也是負責接收後端的資料
<form method="post"傳到後端> <form metod="get"做為測試的功能 ，能在網址看到資料安全性不好>
呼叫函式 可以用 id 、 name 兩個可以放在一起，命名規則都要一樣，方便處理
name 後端 讀取用
id 前端 使用
enctype 編碼類型 <input type="file">
accept 允許上傳的檔案類型 (pptx ..)
autocomplete="off" cookie的功能關掉 (預設 ON)
cookie 作為令牌的功能，如果之前有登入過 ，他就會發令牌給你，下次再進入網站後，就不用重新登入一次，但是有安全疑慮 (第三者攻擊)
